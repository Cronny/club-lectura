# Agent Instructions

This is a **Quartz v4** static site generator project customized for a Spanish book club. Markdown content lives in `content/`, configuration is in `quartz.config.ts` and `quartz.layout.ts`.

## Commands

Run in this order when making changes:

```bash
npm run format    # Prettier (required before check)
npm run check     # TypeScript + Prettier validation
npm test          # Run tests
npx quartz build  # Build the site
```

### Development

```bash
npm run docs           # Build and serve docs/ directory
npx quartz build --serve   # Build and serve content/ (default)
```

The Quartz CLI is at `./quartz/bootstrap-cli.mjs` (invoked via `npx quartz`).

## Project Structure

- **Content**: `content/` - Markdown files, Spanish locale (`es-ES`)
- **Config**: `quartz.config.ts` - Site settings, plugins, theme
- **Layout**: `quartz.layout.ts` - Component placement, page structure
- **Quartz engine**: `quartz/` - Core framework code
- **Output**: `public/` (build artifacts, gitignored)

## Key Details

- **Node version**: v22+ required (`.node-version` specifies v22.16.0)
- **npm version**: >= 10.9.2 required
- **Module system**: ESM only (`"type": "module"` in package.json)
- **JSX**: Preact with `react-jsx` transform
- **Prettier**: No semicolons, 2-space tabs, 100 char width, trailing commas
- **Ignored patterns**: `private/`, `templates/`, `.obsidian/` (configured in quartz.config.ts:20)

## Workflow Notes

- **CI checks**: `npm run check` runs TypeScript and Prettier validation (must pass before merge)
- **Plugin customization**: Comment out `Plugin.CustomOgImages()` in quartz.config.ts:92 to speed up builds
- **Content source**: The site serves `content/` by default; use `npm run docs` to serve `docs/` instead
- **Locale**: Site uses `es-ES` locale (quartz.config.ts:18)

## Common Mistakes

- Running `npm run check` before `npm run format` (Prettier validation will fail on unformatted code)
- Missing Node 22+ or npm 10.9.2+ (hard requirements in package.json:22-24)
- Editing `public/` directly (it's generated by `npx quartz build`)
- Forgetting that Quartz uses Preact, not React (JSX differences may matter)
